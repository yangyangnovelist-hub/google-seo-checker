# 抓取和索引编制主题概览

这部分介绍了如何控制 Google 对您内容的查找和解析以使其显示在 Google 搜索和其他 Google 产品和服务中，以及如何阻止 Google 抓取您网站上的特定内容。

以下是每个网页的简介。如需大致了解抓取和索引编制功能，请参阅我们的 [Google 搜索的运作方式](https://developers.google.com/search/docs/fundamentals/how-search-works?hl=zh-cn)指南。

主题

[Google 编入索引的文件类型](https://developers.google.com/search/docs/crawling-indexing/indexable-file-types?hl=zh-cn)

Google 可将大多数类型的网页和文件内容编入索引。查看 Google 搜索可编入索引的最常见文件类型的列表。

[网址结构](https://developers.google.com/search/docs/crawling-indexing/url-structure?hl=zh-cn)

建议您组织一下内容，使网址结构合乎逻辑并易于人们理解。

[站点地图](https://developers.google.com/search/docs/crawling-indexing/sitemaps/overview?hl=zh-cn)

将网站上新增或更新的网页告知 Google。

抓取工具管理

- [请求 Google 重新抓取您的网址](https://developers.google.com/search/docs/crawling-indexing/ask-google-to-recrawl?hl=zh-cn)
- [管理对分面导航网址的抓取](https://developers.google.com/search/docs/crawling-indexing/crawling-managing-faceted-navigation?hl=zh-cn)
- [面向大型网站所有者的抓取预算管理指南](https://developers.google.com/search/docs/crawling-indexing/large-site-managing-crawl-budget?hl=zh-cn)
- [HTTP 状态代码以及网络连接错误和 DNS 错误对 Google 搜索有何影响](https://developers.google.com/search/docs/crawling-indexing/http-network-errors?hl=zh-cn)
- [Google 抓取工具](https://developers.google.com/search/docs/crawling-indexing/overview-google-crawlers?hl=zh-cn)

[robots.txt](https://developers.google.com/search/docs/crawling-indexing/robots/intro?hl=zh-cn)

robots.txt 文件规定了搜索引擎抓取工具可以/无法请求抓取您网站上的哪些网页或文件。

 [规范化](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls?hl=zh-cn)

 了解什么是网址规范化，以及如何将您网站上的重复网页告知 Google，以避免过度抓取。了解 Google 如何自动检测和处理重复内容，以及如何将**规范网址分配到发现的重复网页群组中。

[移动网站](https://developers.google.com/search/docs/crawling-indexing/mobile?hl=zh-cn)

了解如何针对移动设备优化您的网站，并确保您的网站能被正确抓取和编入索引。

[AMP](https://developers.google.com/search/docs/crawling-indexing/amp?hl=zh-cn)

如果您有 AMP 网页，可通过相应网页了解 AMP 在 Google 搜索中的运作方式。

[JavaScript](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics?hl=zh-cn)

在设计网页和应用时需要考虑一些差异和限制，以适应抓取工具访问和呈现您的内容的方式。

[页面和内容元数据](https://developers.google.com/search/docs/crawling-indexing/special-tags?hl=zh-cn)

- [使用有效的 HTML 指定页面元数据](https://developers.google.com/search/docs/crawling-indexing/valid-page-metadata?hl=zh-cn)
- [Google 可以理解的所有 `meta` 标记](https://developers.google.com/search/docs/crawling-indexing/special-tags?hl=zh-cn)
- [Robots`meta` 标记、`data-nosnippet` 和 X-Robots-Tag 规范](https://developers.google.com/search/docs/crawling-indexing/robots-meta-tag?hl=zh-cn)
- [使用 `noindex``meta` 标记阻止编入索引](https://developers.google.com/search/docs/crawling-indexing/block-indexing?hl=zh-cn)
- [确保链接可供抓取](https://developers.google.com/search/docs/crawling-indexing/links-crawlable?hl=zh-cn)
- [使用 `rel` 属性向 Google 说明您的出站链接的用意](https://developers.google.com/search/docs/crawling-indexing/qualify-outbound-links?hl=zh-cn)

- [从搜索结果中移除您网页上托管的图片](https://developers.google.com/search/docs/crawling-indexing/prevent-images-on-your-page?hl=zh-cn)
- [让隐去的信息不显示在 Google 搜索中](https://developers.google.com/search/docs/crawling-indexing/keep-redacted-information-out?hl=zh-cn)
