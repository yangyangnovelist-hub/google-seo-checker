# Google 搜索的评价系统与您的网站之间的关系

 **评价系统旨在更好地奖励优质评价，其内容包含见解深刻的分析和原创研究，并且由熟知相应主题的专家或爱好者撰写。本页详细介绍了评价系统的运作方式，以及您应如何评估和改进内容。

## 评价系统的运作方式

 评价系统致力于确保用户看到那些分享深度研究的评价，而不是对一堆商品、服务或其他事物做简单总结的贫乏内容。我们会定期持续改进评价系统。

 评价系统旨在评估文章、博文、网页或类似第一方独立内容，这类内容的撰写目的是提供建议、意见或分析。评价系统不会评估第三方评价，例如用户在商品或服务页面的评价部分中发布的评价。

 评价可以关于单一事物、是一对一的比较或建议项目的排名列表。评价可以关于任何主题。可以是对笔记本电脑、冬季夹克、媒体内容（例如电影或视频游戏）之类商品的评价，或对餐馆、时尚品牌等服务和商家的评价。

 评价系统主要在网页一级评估评价内容。不过，对于包含大量评价内容的网站，系统可能会评估网站中的任何内容。如果您的网站上没有大量评价，就不太可能会受到网站级评估。

 目前，此系统适用于全球以下语言：英语、西班牙语、德语、法语、意大利语、越南语、印度尼西亚语、俄语、荷兰语、葡萄牙语、波兰语。

 对于商品，[商品结构化数据](https://developers.google.com/search/docs/appearance/structured-data/product?hl=zh-cn)可能有助于我们更好地识别内容是否为商品评价，但我们并非仅依赖于此类数据。

## 这个系统对我的网站意味着什么？

 如需详细了解如何制作在评价系统中取得成功的内容，请参阅我们[有关如何撰写优质评价的帮助页面](https://developers.google.com/search/docs/specialty/ecommerce/write-high-quality-reviews?hl=zh-cn)。

 如果您已改善内容，受到评价系统影响的内容可能会在一段时间后恢复。但请注意，我们对评价内容的自动评估只是对内容进行排名时所依据的众多因素之一，因此随时可能会出于各种原因而发生变化。
